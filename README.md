"The World in One Day" — a one-page newspaper front page summing up the
world news of **Wednesday 25 November 2026** in a single 1024×1024 image:
Iran saying oil tankers struck mines in the Strait of Hormuz (claim
unconfirmed, Brent near $91), Ukraine's drones hitting two refineries in
Russia's Samara region as Putin vows retaliation, the Australia–Solomon
Islands treaty signed in Canberra with the Solomons dropping its China
pact, hackers breaching the CIA's open-source intelligence system, Asia's
AI stocks tumbling, the sports court giving Senegal its Africa Cup title
back, and a Houthi drone hitting a Riyadh tower, a nor'easter threatening
the Thanksgiving parade, and Trump pardoning turkeys Freedom and Feathers
in the "Also Today" line. Every story happened or was first reported on
25 November 2026 and was cross-checked against public sources before it
was set in type.

`main.py` (Python standard library only, no network) copies the
committed `entry.png` — drawn by `make_image.py` with Pillow — to
`/output/entry.png`, byte for byte, every run.

## Run it

```sh
python3 main.py   # writes /output/entry.png (or $MAKEFUN_OUTPUT_DIR/entry.png)
python3 make_image.py   # regenerates entry.png from the drawing code
```
